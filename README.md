# SyncWatch

SyncWatch — это self-hosted решение для синхронного совместного просмотра видео и фильмов с друзьями в реальном времени. Система позволяет транслировать видеопоток напрямую из браузера хоста любому числу зрителей с автоматической синхронизацией перемотки, паузы и скорости воспроизведения.

Проект разработан для случаев, когда стандартные сервисы совместного просмотра не могут получить доступ к видео (плееры с защитой, закрытые сайты, видео внутри Shadow DOM или сложные онлайн-кинотеатры).

## Ключевые возможности

* Два режима работы:
  * Живой WebM-релей (Relay Mode): захват картинки плеера через Canvas и оригинальной аудиодорожки через Web Audio API с последующей потоковой передачей зрителям по WebSocket/HTTP без потери качества.
  * Прямое проксирование (Proxy Mode): перехват и проксирование прямых ссылок HLS (.m3u8) и MP4 с автоматической подменой заголовков (Referer, Origin, Cookie) для обхода ограничений источников.
* Интеллектуальная синхронизация:
  * Адаптивная подстройка скорости (Pacing Engine): клиенты плавно ускоряются (до 1.1x) или замедляются (до 0.5x/0.9x) в зависимости от запаса буфера без слышимого искажения звука и заиканий.
  * Защита от статтеров: буферная подушка (7-10 секунд) обеспечивает плавный просмотр даже при нестабильном интернет-соединении у участников.
  * Гарантированное доигрывание хвоста: видео никогда не обрывается на последних секундах при завершении трансляции хостом.
* Захват плееров любой сложности:
  * Поддержка плееров внутри Shadow DOM (включая VK Видео, YouTube, Rutube).
  * Корректный захват видео из вложенных iframe.
  * Нормализация меток времени EBML: автоматический сдвиг таймкодов WebM-кластеров к нулю для предотвращения ошибок демуксера в браузерах зрителей.
* Дополнительный функционал:
  * Интерактивная очередь предложений: зрители могут отправлять ссылки на видео прямо через веб-интерфейс.
  * Веб-журнал событий (/logs) для мониторинга задержки, буфера и состояния стрима в реальном времени.

## Стек технологий

* Серверная часть:
  * C# / .NET 8 (ASP.NET Core Kestrel)
  * SignalR (управление комнатой, синхронизация метаданных, паузы/перемотки)
  * WebSockets (приём медиапотока от расширения хоста)
  * Собственный потоковый парсер WebM/EBML с нулевым выделением памяти (Zero-Allocation via ReadOnlySpan)
* Расширение хоста:
  * Firefox WebExtension (Manifest V2)
  * Web Audio API (MediaStreamAudioSource, AudioContext)
  * MediaRecorder API (VP8 / Opus)
  * WebRequest API (перехват потоков m3u8/mp4 и кук)
* Клиентская часть:
  * Vanilla JavaScript, HTML5 Video API
  * SignalR JavaScript Client

## Архитектура работы

1. Режим ретрансляции (Relay Mode):
   * Расширение в браузере хоста находит активный HTML5-видеоплеер.
   * Видеокадры переносятся на виртуальный холст с контролем FPS и битрейта, аудиопоток перехватывается через `mozCaptureStream`.
   * Поток упаковывается в WebM (VP8/Opus) и передаётся по WebSocket на сервер SyncWatch.
   * Сервер разбирает EBML-структуру, формирует инициализирующий заголовок и ретранслирует кластеры зрителям через HTTP-эндпоинт `/api/live`.
2. Синхронизация воспроизведения:
   * Зрители регулярно отправляют размер своего буфера через SignalR хаб.
   * Сервер вычисляет единую комфортную скорость комнаты и рассылает команду `SyncRoomPace`.
   * При перемотке хостом поток мгновенно перезапускается с нужной секунды.

## Установка и запуск

### Требования

* .NET 8.0 SDK (для сборки и запуска сервера)
* Браузер Mozilla Firefox (для хоста трансляции)
* Любой современный браузер для зрителей (Chrome, Firefox, Safari, Edge, мобильные браузеры)

### 1. Запуск сервера

Клонируйте репозиторий:

```bash
git clone https://github.com/your-username/SyncWatch.git
cd SyncWatch
```

Запустите проект:

```bash
dotnet run -c Release
```

По умолчанию сервер запустится на порту `5000`:
* Веб-интерфейс зрителя: `http://localhost:5000`
* Журнал трансляции: `http://localhost:5000/logs`

Для доступа друзей через интернет пробросьте порт `5000` на роутере, используйте белый IP, VPS или туннелирование (Cloudflare Tunnels, ngrok, tailscale, wireguard).

### 2. Установка расширения хоста в Firefox

1. Откройте Firefox и перейдите по адресу `about:debugging#/runtime/this-firefox`.
2. Нажмите кнопку "Загрузить временное дополнение..." (Load Temporary Add-on).
3. Выберите файл `manifest.json`, находящийся в папке `pluginFirefox/SyncWatch.Interceptor/`.

### 3. Настройка расширения

1. Нажмите на иконку расширения SyncWatch на панели браузера.
2. В поле "Сервер" укажите адрес вашего запущенного сервера (например, `http://localhost:5000` или внешний домен/IP вашего сервера) и нажмите "Сохранить адрес".
3. Выберите желаемое разрешение захвата (720p, 1080p), битрейт и частоту кадров.

## Использование

1. Хост открывает в Firefox вкладку с нужным фильмом или видео (YouTube, VK, любой онлайн-плеер).
2. Нажмите сочетание клавиш `Alt + Shift + V` или откройте всплывающее окно расширения и нажмите "Захватить этот плеер".
3. Появится уведомление об успешном захвате.
4. Друзья переходят по адресу вашего сервера (например, `http://IP_ВАШЕГО_СЕРВЕРА:5000`).
5. Воспроизведение, пауза и перемотка у зрителей синхронизированы с хостом. Зрители также могут управлять воспроизведением, если у них есть доступ к панели плеера.

## Конфигурация захвата

В меню расширения доступны следующие параметры:

* Разрешение: от 480p до 1440p (исходная картинка пропорционально масштабируется для снижения нагрузки на канал).
* Битрейт: от 0.3 до 20 Мбит/с.
* Частота кадров (FPS): ручная настройка от 5 до 60 кадров/с либо автоматическое определение частоты исходного видео.
